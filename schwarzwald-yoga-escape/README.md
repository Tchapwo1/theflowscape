# Schwarzwald Yoga Escape — landing page

A responsive static landing-page prototype for the fictional retreat brand.

## Preview
Open `index.html` in a browser.

## Publish
Upload the contents of this folder to Netlify, or deploy the folder as a static site.

## Important before launch
The waitlist form is currently a front-end demonstration. It validates the fields and shows a confirmation state, but it does NOT transmit or store registrations. Connect it to a form backend (for example Netlify Forms, Formspree, or your CRM) before publishing and collecting real visitor information.

Replace `hello@example.com` with a real contact address. Confirm venue, retreat dates, pricing, instructor details, accessibility and dietary arrangements before making factual claims.

Photography is loaded from Unsplash image URLs and Google Fonts are loaded from Google Fonts, so an internet connection is required for those assets.
