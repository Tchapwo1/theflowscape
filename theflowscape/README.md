# The Flowscape — Umbrella Retreat Collection

The flagship umbrella portal website for **The Flowscape** (`theflowscape.com`), curating boutique yoga and wellness sanctuaries across Europe:
- 🌲 **Schwarzwald Yoga Escape** (Germany)
- 🇫🇷 **Provence Yoga Escape** (France)
- 🇬🇧 **London Yoga Escape** (United Kingdom)
- ✦ **Future Sanctuaries** (Tuscany & Swiss Alps)

## Features
- **Signature Brand Identity**: Incorporates the **Red Lotus** emblem and refined luxury typography.
- **Interactive Sanctuary Explorer**: Filter retreats by landscape type (Forest & Mountain, Mediterranean Terroir, Urban Sanctuaries).
- **The Four Pillars of Flowscape**: Sense of Place, Dual Rhythm Practice, Soil-to-Table Nutrition, and Intimate Scale.
- **Priority Circle Global Waitlist**: Interactive membership application allowing guests to select multiple destinations and travel styles.
- **Responsive & Modern**: Optimized for mobile, tablet, and 4K desktop screens with smooth scrolling navigation.
