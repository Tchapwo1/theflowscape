# Provence Yoga Escape — Landing Page

A responsive static landing page for **Provence Yoga Escape**, an intimate wellness retreat nestled in the Luberon Valley, South of France.

## Preview
Open `index.html` directly in your browser or serve locally with Python:

```bash
python -m http.server 3001
```

## Features
- **South of France Aesthetic**: Earthy cypress, warm terracotta, golden honey, and sun-bleached stone palette.
- **Curated Content**: 3-day Mediterranean flow, Luberon location facts, 18th-century stone bastide lodging details, philosophy, and retreat FAQs.
- **Responsive Layout**: Designed for mobile, tablet, and desktop with smooth scrolling and accessible navigation.
- **Interactive Waitlist Form**: Front-end interactive early-access registration with feedback states.
- **Photography**: High-resolution Unsplash imagery capturing Provence's lavender fields, terrace yoga, and terroir feasts.

## Deployment
Deploy the contents of this folder directly to Netlify, Vercel, or GitHub Pages.
