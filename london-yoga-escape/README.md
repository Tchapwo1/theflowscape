# London Yoga Escape — Landing Page

A responsive static landing page for **London Yoga Escape**, an urban wellness retreat located in the leafy enclaves of Richmond and Hampstead, London.

## Preview
Open `index.html` directly in your browser or run a local server:

```bash
python -m http.server 3002
```

## Features
- **Refined British Botanical Aesthetic**: Deep racing/ivy green, warm London stone, muted brass, and sage accents.
- **Curated Urban Retreat Experience**: Glasshouse vinyasa, acoustic sound baths, Richmond Park & Hampstead walking meditations, plant-forward botanical dining, and boutique Victorian townhouse accommodation.
- **Residential & Day-Pass Options**: Designed for both overnight guests and local Londoners seeking a non-residential weekend reset.
- **Fully Responsive**: Mobile-first navigation, fluid typography, and clean layouts.
- **Interactive Waitlist**: Form with season preferences and instant confirmation state.

## Deployment
Deploy the contents of this folder directly to Netlify, Vercel, or GitHub Pages.
